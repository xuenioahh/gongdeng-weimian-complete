# 《宫灯未眠》完整游戏源码 · 本地工程版

这是可以继续开发的完整本地工程，不是只包含图片链接的展示页，也不是只有一个打包 HTML 的下载页。当前构建版本为 **v146**。

## 工程内容

- `index.html`：游戏入口页面。
- `app.js`：完整剧情逻辑、人物数据、章节数据、选项、状态机、存读档、章节跳转、结局瓷谱和界面交互。
- `styles.css`：完整界面样式、立绘布局、瓷器翻面效果、章节与人物页面样式。
- `assets/`：167 个本地图片文件，包含人物立绘、瓷器图、界面资源和剧情图；当前运行路线挂载的叙事图为 64 张，不依赖远程图片或 Base64 占位。
- `src/`、`styles/`：剧情、人物、状态、界面与样式的模块化源文件。
- `scripts/build.py`：按清单从模块构建 `app.js` 与 `styles.css`。
- `SOURCE_MANIFEST.json`：源码块与资源清单。
- `tests/`：回归测试文件。

## 运行

直接打开 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8000
```

再访问 `http://localhost:8000/`。

不需要安装 npm，不需要 CDN，不需要联网接口。所有图片、CSS、JavaScript 和剧情逻辑均在本目录内。

## 继续创作的位置

- 改章节与选项：编辑 `src/data/chapters/`；改人物和皇嗣数据：编辑 `src/data/people.js`、`src/data/children.js` 及对应状态模块。
- 改颜色、布局、动画和卡片：编辑 `styles/` 下的源文件。
- 改剧情环境与静默幕：编辑 `src/data/scene-air.js` 和 `src/effects/environment-director.js`。
- 修改源文件后运行 `python3 scripts/build.py`，再检查 `app.js` 与 `styles.css`。
- 替换人物图或瓷器图：替换 `assets/` 中对应文件，并保持文件名不变；也可以同步修改 `app.js` 中的资源引用。
- 入口页面结构：编辑 `index.html`。
