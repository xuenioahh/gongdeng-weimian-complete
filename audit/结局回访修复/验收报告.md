# 《宫灯未眠》结局回访修复

修改已接入本地工程的源码与构建文件。恢复备份位于 `backups/finale-20261010/`。没有另做结局图鉴、独立词谱页或新章节，没有修改结局正文、七段走马灯诗句、首页六句题辞、关键引文与结局人物命运。

## 原有问题及位置

1. `src/ui/finale-reveal.js / endingFinale146`：完成标记只让结局全文显示，走马灯结束仍回到同一正文模板。入口仅有瓷谱、大事录和重播，缺少明确的全剧终收卷菜单及返回目录、首页的结束操作。
2. `src/ui/final-montage.js / finalMontageView147、mountFinalMontage147`：播放中只有下一幕、暂停和跳过；缺少明确的退出观看按钮与键盘退出。旧代码依赖全局导航让人离开，画面内没有统一的上级返回。
3. `src/ui/bindings.js / data-replay、src/core/replay.js / replay136`：章节“重读”重建状态并改写之后记录。这是重新选择剧情的功能，不能拿来实现只读的结局回访。
4. `src/core/save.js / save、pack、restore`：自动保存直接打包当前全局 state。若仅把 index 暂时跳到卷终，播放帧检查点、保存或读档前备份会把回顾状态写入正式进度。
5. `src/ui/people-view.js` 及既有大事录：瓷谱解锁依赖卷终 index，离开以后主要靠“正文”导航回去；缺少明确的返回卷终、以及重新开始或读取早期存档后访问已完成结局的入口。
6. `src/ui/final-montage.js / picture、stop`：淡出图层的延迟删除计时器未归入退出清理；图片加载超时虽能清除，加载承诺没有统一取消。异步开启配乐也需要在退出之后确认已关闭。
7. 正式阅读模式的320像素窄屏：最后标题仍占着空的引文、诗句行，标题顶部会超出舞台。已通过逐幕几何检查发现并修复。

原代码不是每次都会永久黑屏；问题是缺少完整的结束／返回／回访路径，并且直接复用章节重读会污染进度。这次修复没有以刷新页面作为返回操作。

## 最终流程

首次完成：正式终章原有七幕 → 最终结局正文渐显（可显示全文）→ 原有走马灯、七段诗句与尾声 → 原有“宫灯未眠”及最后淡出 → 全剧终收卷菜单。

菜单提供：重温走马灯、回看结局、人物瓷谱、返回目录、返回首页。目录复用现有大事录，在其中加入已阅结局的回访按钮；没有新建重复的菜单页面。

回访：首页／顶部卷终回访／大事录中的已阅之卷 → 指定已完成结局快照 → 结局正文、走马灯、瓷谱或收卷菜单。回顾期间可返回卷终，也可返回游戏；后者恢复进入之前的正式进度与页面。

播放中：退出观看或Esc → 原上级页面；首次正式播放退出可直接进入收卷菜单。跳过走马灯 → 收卷菜单。重温始终从第一幕开始，不重做剧情选择或奖励结算。

## 解锁和保存边界

- 沿用原条件：`index === CHAPTERS.length` 且 `flags.v82FinaleComplete`。只有满足条件的已完成存档才登记和显示。
- 快照以继后路线、既有继位标记、沈知微既有结局标记区分；同类新的正式完成替换该类快照，其他已完成分支保留。目录可指定已经记录的分支。
- 旧版已完成自动档、手动档和导入档兼容；重新开始或读取早期档不会删除已阅结局记录。
- 回顾只改变临时显示状态。自动保存不写回；手动保存、导出打包和读档前备份使用回顾之前的正式进度。
- 回顾中刷新按正式自动档恢复，不把回顾的卷终index当成新进度。
- 未完成的结局不提前开放，也没有为测试修改剧情解锁条件。
