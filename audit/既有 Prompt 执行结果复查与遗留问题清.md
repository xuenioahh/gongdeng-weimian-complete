最后在结尾处设计一个滚动总结式的结局 根据作者之前所有的选项 做一个大总结激发读者共鸣和思考 看看怎么设计有趣一些
可以把它设计成 “卷终回望：这一朝，由你留下”。放在张元照终章之后，再进入人物瓷谱。读者刚看完她接过权力的结局，接着看见自己曾经作出的决定，怎样留在这些人的生平里。

最动人的地方，是让读者认出：这是我走过的那一朝。

建议这样展开：

1．先从一件很小的事开始

不要开场就总结帝王功过。先回收本次阅读中真实出现过的一件日常：一碟杏仁酥、一句问路、一次留座、一支准许留下的银簪。

画面只留物件、人物名字和当时的一句原话。稍停以后，再出现她后来的人生记录。

这里不写“你还记得吗”，也不替读者宣布感动。让前后的距离自己产生重量。

2．滚动中交替出现“当时”与“后来”

这是整个结局最值得做的特色：

当时的选择
明旨重审沈氏旧案。

后来留下的记载
帝命重审沈知微旧案。案定，昭雪，并将当年御批入档。

上面保留实际选择，下面用史书工笔写已经发生的结果。点击这一页，可以展开原场景与后续回应。

同一个决定可以隔几页再次出现：第一次是皇帝说出的话，第二次是承受这句话的人后来去了哪里。这样，滚动本身就能呈现时间与因果。

3．人物依次经过，但每个人留下不同的东西

人物页不统一套用“她的一生……”模板。

有人留下册命，有人留下没有递出去的家书，有人留下实际改过的文书，有人仍活着，仍在做普通事情。素材必须来自现有正文。

每人滚动展示一段短传；点击姓名，展开完整小传。不以位分高低决定谁值得被记住，也不要把所有人生都写成死亡与遗憾。

顾明宜、沈知微、闻人三人、周清漪、邵明贞、张元照之间，可穿插方小满、阿芙等人的日常，让回望有呼吸。

4．继后部分根据本次经历真正改变

直接册后时，回收张元照历次册命、参与过的事情与接印经过。

先邵后张时，必须先留下邵明贞执掌中宫期间的具体决定和后果，再写交印。不能让她在总结里又变成一句过渡。

这里可以出现同一方凤印的两次画面：第一次旁边是邵明贞当时签过的文书，第二次是张元照实际接手的事务。物件相同，责任已经换了人。

5．最后让史书记载停下，让读者自己回看

滚动结束，不给“明君”“暴君”“最佳结局”评级。屏幕留下三个入口：

重读这一朝：本次完整大事录。
再见一个人：人物小传与结局瓷谱。
回到那一刻：只读回看某次决定，保留当前结局。
最后的问题也随前情变化。例如本次保留了旧案御批，可以问：

若再回到那一天，你还会把自己的御批一并留下吗？

问题必须对应读者真正做过的事。回答可以只留在心里，也可以点击回看；无需再选择一道“正确答案”。

所有选项都参与整理，但滚动正文建议精选 12—18个回收点，完整细节放入可展开的纪事。支持手动翻阅、缓缓播放、随时暂停；展开资料时自动停止，避免文字还没读完就滑走。

下面是节奏和互动示意，未接入实际存档；其中旧案的另一种前情仅用于演示，正式版本应逐项核对现有剧情。


# 《宫灯未眠》重头戏逐场研究：普通读者体验、因果与情节设计检查 Prompt

你是一名中文小说编辑与互动叙事评审。请阅读我提供的《宫灯未眠／承熙纪事》当前版本，逐场研究重头戏。

核心任务：判断前因后果和人物行动是否成立，章节与分支是否串得起来，现有文字是否足以让读者经历这场戏，以及情节设计是否清楚、有效、有趣。请具体指出哪里看不懂、哪里无聊、哪里不合理、哪里值得保留，再给出可执行的修订方案。

先以普通读者顺序阅读，再以编辑回查结构。不要从作者知道的结局倒推读者应该明白什么，也不要只做词语润色。

## 一、阅读范围和事实依据

1. 以本次明确确认的设定与最新实际运行内容为依据。旧稿、图片说明、人物设定卡和开发注释，不能替正文完成解释。
2. 先确认实际入口、章节、场景及路线；若只有文本，只评估已提供文本。不得声称测试了未运行的选项或阅读了缺失章节。
3. 分清已确认事实、人物证言、皇帝推测、作者后台设定和待核实信息。它们不能混为同一个真相。
4. 不擅自新增人物、皇嗣、死亡、案件真相或感情线。特别保留已确认的含章定位、元照晋位及继后路线。
5. 默认交付审读报告、设计判断和修订方案；若本轮明确要求修改项目，则直接落实已授权修复，并同步检查状态、后文与记录。不要要求用户再次确认已经授权的常规修复。

## 二、先划分真正的重头戏

重头戏可以跨越多幕或两章，不等于每个标题或每个选择页。请按“前期铺垫—事件发生—交锋／决定—执行—余波”划定完整范围，不能只读高潮一段。

重大产育、刺杀、旧案、疫病、死亡、册封、交印等可作为候选；实际范围仍须从正文识别。不要根据旧清单硬套章节编号。

建立总表：场景 ID／标题｜所在章节及时间｜参与者与当时身份｜核心事件｜相关前情｜立即结果｜后续影响｜涉及路线｜审读状态。

说明这场戏为什么被视为重点：它改变了谁的处境，或者让读者认识到什么此前看不见的人物与关系。不能只说“深化主题”。

## 三、第一遍：普通读者顺读

模拟一名愿意读宫廷小说、记得主要人物但没有背熟资料的人。不要求他熟悉所有官署、程序、旧案细节，也不默认他会打开人物页才能看懂正文。

阅读时只使用此刻已经出现的内容。记录关键位置的自然反应：

- 我知道现在何时、何地、谁在场吗？
- 我知道正在发生什么、大家在处理什么问题吗？
- 我想知道的下一件事是什么？
- 我在担心谁、期待什么，还是尚未产生关注？
- 哪一句、哪次跳转让我失去方向？
- 哪一段让我想略读？为什么？
- 哪个动作、对白或结果让我记住了这场戏？

记录格式：位置与原文｜此刻能理解什么｜疑问／感受｜后文是否及时回应。

这是一次模拟阅读，不是真实读者调查。不能用“所有读者都会觉得”代替文本证据。

### 区分三种疑问

**有效悬念**：事情清楚，答案尚未揭晓，如谁改了这张单、谁会承担后果。

**可接受的含蓄**：行为与语境足以支持理解，人物没有直接说满。

**理解障碍**：连发生什么、争什么、为什么做都不知道。

前两种可以保留。第三种必须修，不得称为“高级留白”。后文的解释不能自动抹掉读者当时无法理解选择的问题。

## 四、第二遍：前因后果与故事串联

为每场戏写出：已有前情 → 此时的触发 → 人物目的 → 实际阻碍 → 行动／选择 → 执行 → 当场结果 → 后续回应。

每一环标出正文依据。缺一环要说明读者会误解什么，不能只写“因果不足”。

逐项检查：

- 为什么在此时发生，和上一场有何联系？
- 关键人物为什么到场或缺席，是否靠连续巧合推动？
- 关键道具、证据、命令从哪里来，经谁的手？
- 人物有权做这件事吗，谁实际执行？
- 当时有哪些合理办法，为什么选了这一种？
- 事件的时限、距离、空间和人数是否足以理解？
- 调查、核实、结案、御前裁断、公布处分是否区分？
- 结果是否由已有行动产生，还是突然追加信息强行收束？
- 余波有没有真正改变后面的生活、关系、称谓、权限或去留？
- 分支汇合时，前情差别有没有消失或相互矛盾？

不要用“宫里就是这样”“她很聪明”“朝臣会反对”补因果。说明具体人物、依据、行为与影响。

## 五、人物是否像活人，行动是否成立

逐人核对：当下想要什么、知道什么、不知道什么、害怕什么、能够做什么，以及行动的实际代价。

检查：

- 是否突然知道隐藏信息，或突然忘记已知事实？
- 是否为推动下一幕而违背既有经验与利益？
- 是否只有观点，没有具体目的和行动？
- 是否所有人都谨慎、聪明、善于说理，缺少生活差别？
- 配角是否只负责递纸、送证据、说一句主题台词？
- 感情变化是否得到足够铺垫，还是一次谈话就完成？
- 皇帝是否全知全能，或总能在事后用正确解释免除自己的责任？

允许人物误判、犹豫、情绪化和自相矛盾，判断是否符合当时信息与性格。不要把合理性等同于每个人都采用最优办法。

不要用现代道德立场单独判定角色行为不成立，也不能用“古代如此”替不合理行为开脱。涉及关键制度，区分项目自定规则与需核实的历史说法；不要编造历史依据。

## 六、现有叙述能否撑起这场重头戏

重点判断：作者说它重大，读者是否实际经历了它。

检查：

- 开场是否有必要的时间、地点、人物、状态与承接？
- 场景中具体发生了哪些动作，而不只是旁白概述？
- 核心争执究竟在决定哪件可以执行的事？
- 读者是否看得见风险、压力和变化？
- 关键事实出现的先后顺序是否便于理解？
- 转折有没有铺垫，决定有没有过程？
- 结果之后是否有必要反应与余波？
- 是否用两句概述跳过三个月、一年或重大关系变化？
- 是否为追求慢而反复说同一个意思？

据此明确归类：已写成完整场景／重要环节缺失／提纲式概述／信息过载／拖长而无推进。

不硬性规定字数、对白比例或每幕感官数量。先指出缺少哪一段体验，再决定扩写、压缩、调序或保留。

正文视角须正确。皇帝未亲见的事件只能通过可信消息、证言或明确切换的视角呈现，不靠无标记的全知镜头增加沉浸。

## 七、设计是否有效、有趣、有意义

“有趣”可以是好奇、期待、紧张、亲近、犹豫、悲伤或一次轻松的笑。不能把有效设计等同于爽感、反转、伤亡和大量按钮。

每场回答：

1. 读者进入时，最值得追下去的问题是什么？
2. 场景过程中，信息、处境或关系发生了什么变化？
3. 读者为什么会关心其中的人？依据在哪里？
4. 有没有这一场独有的动作、交谈或困境？
5. 设计有没有落实，还是只在设定卡里很精彩？
6. 和此前的戏是否重复同一种讨论与结论？
7. 如果删掉这一场，会失去什么具体内容？
8. 结束后留下的印象是什么？是否只是记住作者宣布的道理？

没有重大主线后果的日常戏也可以值得保留，它可能建立亲近感、人物差别或节奏。删戏判断不能只看是否提供证据或改变位分。

明确给出：保留并强化／缩短／合并／调整位置／重构设计。解释收益和可能损失，不默认所有问题都靠加字解决。

## 八、互动是否值得点，选项是否看得懂

先从普通玩家角度读选项，再检查实际结果：

- 玩家知道自己具体在做什么吗？
- 行动是否符合皇帝当时的权限与已知信息？
- 选项有实际差别，还是同一个答案换说法？
- 风险是否有合理提示，还是靠事后揭示隐藏规则惩罚玩家？
- 点击后是否马上得到动作或反馈？
- 延迟后果是否被后文回收？
- 选项承诺的事与实际结算是否一致？
- 是否所有选择都只能赞同作者指定的正确人物？
- 锁定原因是否清楚，是否存在无法继续的阅读页？

既定死亡或既定主线可以保留，选择仍能影响调查、照料、关系和善后。不能用“救下她”命名实际无法救人的选项，也不能为了让选择有效擅自改掉既定结局。

情感选择、日常选择可以有局部效果，不要求每个按钮改变整个故事。没有适合交互的位置时，允许完整阅读场景，不强行加小游戏。

## 九、沉浸、语言与视觉是否共同支持理解

检查读者能否在脑中形成事件的基本画面：谁在哪里、正在做什么、看见和听见什么。感官细节须来自现场，不让天气自动代替情绪。

专查：

- 越界、失礼、旧案、那件事等表达是否缺少具体所指。
- 一问一答像辩论提纲，所有人都说主题金句。
- 手指压册页、看门、抿茶等动作反复使用却无实际作用。
- 旁白不断解释“这意味着”“她终于学会”，读者却没见过转变。
- 古风过重、名词堆叠和称谓混乱是否增加理解负担。
- 配图是否错位、剧透或合并不同时间的事情。
- 图片中的人物与当时身份、年龄、服饰、动作是否一致。

只在空间或行为确实难懂时建议局部现场图；文字足够时不强行补图。音乐和特效不能修复缺失的因果。

## 十、用具体反例定位结构问题

以下仅作检查类型，不当成当前项目已经存在的事实：

**三皇子事件只谈“越界”“失礼”。**读者是否知道实际发生什么、已有处分是什么、邵明贞和张元照此刻需要决定什么？如果不知道，先补清必要事实，不能只把对白写得更尖锐。

**火灾中张元照开门。**读者是否知道起火处、拥堵通道、受困者、可用的门与等候风险？皇帝何时抵达、依据谁的证言判断？缺空间信息时，简单问答撑不起紧急决定。

**邵后交印。**读者是否经历她的治理、案件影响、卸任原因与未了事务？凤印被拒接后在哪里？下一位接印为何合理？不能仅靠她来送印、元照恰好送名单、皇帝随口询问就完成重大交接。

**顾后临终或皇帝驾崩。**此前身体变化、现场人员、消息传递、当事人的未竟之事和死后处理是否存在？不能只增加悲伤修辞，将两句死亡通知称作完整重头戏。

## 十一、每场固定输出格式

### 1. 一句话读者判断

直接说清：看得懂但平淡／有张力但关键事实不清／逻辑成立但像概要／情感已经成立／需要重构等，并给依据。

### 2. 三句复述

用普通读者能听懂的话说：此前发生什么；这一场处理什么；结束后改变什么。若无法复述，标出正文缺口。

### 3. 读者体验记录

列出最关键的三至六处阅读位置：理解、期待、困惑、略读或印象。引用原句或稳定场景位置，不只报抽象问题。

### 4. 因果与人物核对

用简表列出缺失环节、对应证据与具体影响；区分作者没交代、人物不知道和故意悬念。

### 5. 设计有效性结论

回答为什么值得读、独特之处是否落实、是否重复、是否需要保留。允许得出“当前设计收益不够，建议合并或删减”。

### 6. 修订方案

优先给最小有效修法：具体在哪一幕补什么、删什么、移动什么，以及怎样回应后文。需要结构重写时，再给完整场景安排。

可示范重写最关键的一至三段。已有事实与人物立场保持一致；新增事实或新设计明确标为提案，不混进既定设定。

### 7. 复读验收

修改后重新顺读，回答：现在能否复述核心问题；是否知道选择会做什么；是否有理由继续；原有有效之处是否保留。不能只因字数增加或语言更古雅就判为通过。

## 十二、全局总结与执行顺序

先交付全部候选重头戏的清单与审读范围，再每批精读一至三场。每场连读必要前情和后续，避免只点评孤立段落。

最终汇总：

- 最值得保留的三类设计及具体依据。
- 最严重的理解障碍、因果问题和人物失真。
- 重复的冲突、模板对白与失效的交互。
- 应扩写、压缩、合并或调整位置的场景。
- 哪些设定需要澄清，哪些只是审美偏好。
- 已完成、待修订、缺少材料、未验证分别列出。

优先修复：看不懂／无法选择 → 因果与状态矛盾 → 人物行动不成立 → 重头戏未展开 → 互动回收不足 → 节奏与语言。

可以分别给清楚度、因果、人物、场景展开、吸引力和互动各五分，但每项须有文本依据；非互动场景可标不适用，缺少前后文可标待评。不要用平均分掩盖核心事件讲不清，也不冒充真实读者数据。

## 十三、模拟读者反馈总结

完成每批重头戏审读后，额外输出一份 Markdown 格式的“模拟读者反馈”。

### 一、模拟读者的区别

默认采用以下四种阅读倾向：

1. **第一次阅读的普通读者**
   没有背熟人物资料，关注是否知道谁在做什么、为什么发生、选项是什么意思。最能暴露称谓混乱、前情缺失和理解障碍。

2. **关注人物与情感的读者**
   关注人物是否像活人、关系变化是否可信、某次决定是否让自己心疼或失望。不能只评价人物“善良”“聪明”，要指出具体动作与经历。

3. **关注情节与互动的读者**
   关注事情有没有推进、选择是否值得点、后果是否兑现、分支是否真的不同。也关注有没有连续几页只换说法、不发生新事情。

4. **愿意细读的古风小说读者**
   关注语言是否自然、场景有没有画面、制度词是否妨碍理解、人物说话有没有区别。不能把“古雅”自动当成优点。

若增加第五位，可采用“重读并比较另一条路线的读者”，但只有实际阅读过对应路线，才能评价路线差异。材料不足时不得编造比较。

这些倾向只是观察角度，不是固定人设。不要让每位读者只能谈一种问题，也不要预设四人一定意见不同。

### 二、反馈必须像读后感，而不是换了称呼的编辑报告

每位读者先用第一人称写一段自然反馈，约150—250字。允许直接说：

- “我读到这里才知道他们在争什么，前面那次选择已经点完了。”
- “我知道这件事很严重，但还没看到她为什么非得这样做。”
- “这一句我记住了，因为前面她确实做过相反的事。”
- “我愿意看她们说完，但这三轮问答一直在重复同一个意思。”
- “我不赞同这个人的决定，可我能理解她为什么会这么选。”

以上只是表达方式示例，不得直接套进所有场景。

每段反馈至少提到一处实际原文、动作、选项或结果。少用“张力不足”“深化主题”“人物弧光”等编辑术语。

不要假装读者知道作者的设计意图。读者没有看懂，就如实写没有看懂；不能替作者补出缺失的解释。

用普通、直接的语言总结：

**共同卡住的地方：**

**最值得保留的地方：**

**如果只改三处：**

### 六、反馈边界

- 不编造“读者都哭了”“大多数人会弃文”等结论。
- 不用不同读者姓名制造真实调查的假象。
- 不让四位读者轮流重复编辑报告。

- 区分“我不喜欢她的决定”与“我不理解她为什么这样决定”。

- 句子清楚、自然，读得出声音。

- 每一行承担一个完整的意思，不把正常句子机械切碎。
- 行数以内容需要为准，整体保持简短，不能扩成另一篇终章。
- 感情通过景物、动作和记忆相互照应，不直接宣布“她很悲伤”“她终于明白”。
- 保留人物的疲惫、迟疑与牵挂，不能写成毫无重量的胜利。

- 不虚构故人临终原话，不让死者替她认可掌权。

## 五、逐行出现的呈现效果

采用“整行缓缓浮现”，不要逐字打字。

1. 标题先出现，正文随后按阅读顺序逐行淡入。
2. 可有极轻微的向上移动，避免明显滑动、闪烁或循环动画。
3. 已出现的文字保持可见，不随下一行消失。
4. 行间间隔根据句长调整，段落之间留更长停顿；避免固定速度让长句来不及读。
5. “宫灯未眠”单独出现，并留出停顿。
6. 最后一行出现后，停留在完整终页，再显示“人物瓷谱”“卷终回望”等已有入口。
7. 提供低干扰的“显示全文”按钮，可立即结束动画。不能强迫读者等待。
