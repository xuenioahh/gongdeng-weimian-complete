这次要改的不是动画速度、颜色或简单的淡入淡出，而是走马灯的整个视觉表现方式。

比如“琴弦断了”，现在如果只是几根线条突然断开、消失，确实会像简单的 SVG 演示，而不是古风剧情中的重要瞬间。

我建议把终章走马灯升级为电影式回忆蒙太奇：每个关键记忆都应该有具体的场景、物件、光影、声音和动作。琴弦断裂时，玩家看到的不应只是线条，而是一张真正的古琴，在幽暗灯火下绷紧、震颤、崩断，最后留下一声戛然而止的琴音。

# 《宫灯未眠》终章走马灯：电影级叙事动画与视觉表现全面升级

## 一、核心任务

请检查《宫灯未眠》当前正式版本中所有结局走马灯、人物回忆、诗词演出及关键物件动画。

**一些动画只有简单的几何形状、线条和基础 CSS 位移，看起来像临时制作的结构示意图，缺乏真实物件的质感、动作细节和情绪感染力。**

尤其是“琴弦断裂”的动画。

目前这种简单线条式表现无法支撑故事本身具有的文学感染力，甚至可能破坏原本应当悲伤、震撼的瞬间。

本次必须进行真正的视觉重构。

目标是将走马灯升级成：

**高品质古风互动叙事游戏的电影式回忆演出。**

不仅要有动画，而且要有构图、物件美术、光影、动作节奏、声音设计和场景间的情绪联系。

## 二、第一优先级：彻底重做“琴弦断裂”动画

这是本次的重点验收场景。

### 1. 重建具有真实古琴质感的画面

不要只画几根平行直线代表琴弦。

必须让玩家一眼认出这是一张古琴。

画面中应有：

- 传统七弦古琴的真实基本形制
- 修长、微微起伏的琴身轮廓
- 深色漆木表面
- 克制而细腻的漆面反光
- 琴弦的真实间距、粗细与走向
- 弦影落在琴面上的微弱变化
- 古琴与周围桌案、灯火的空间关系

可使用经过精修的透明素材、分层 SVG、Canvas 或其他适合项目架构的真实视觉资源。

**优先采用高质量美术素材作为琴体，再对琴弦做独立可控的动画。**

不要用几十个 CSS 边框或简单几何形状硬拼一张廉价的古琴。

### 2. 具体动画分镜

整个动画建议约5—7秒，按真实演出效果调整。

**镜头一：琴音未绝（0—1.5秒）**

昏暗的宫室里，一盏灯静静燃着。

镜头由远及近，缓慢靠近琴面。

琴身漆面映着微弱暖光。

琴弦仍在轻微震动。

背景中保留一点宫廷夜色，不要将整张琴悬浮在纯黑背景上。

**镜头二：弦将断（1.5—2.8秒）**

镜头聚焦其中一根琴弦。

琴音产生细微变化。

弦的振动逐渐变得不稳定。

可以通过真实的波动、运动模糊和细微光影体现张力。

不要让七根弦同时夸张地抖动。

**镜头三：断弦（约2.8秒）**

一声短促、清晰、带有金石余响的崩弦声。

其中一根琴弦突然断开。

必须体现：

- 断点明确
- 两段弦向各自受力方向快速回弹
- 断弦产生瞬间的动态模糊
- 其余琴弦可有极轻微的共振
- 回弹速度先快后慢，符合物理直觉
- 断裂后留有清楚可辨的断弦状态

不是把一条直线拆成两条，然后简单隐藏。

不要出现爆炸、火星、巨大的白色闪光或不合逻辑的碎片飞溅。

**镜头四：余音散尽（3—5秒）**

断开的弦仍有一点残余颤动，随后逐渐停下。

原本连贯的琴音戛然而止。

其余声音随之退去。

画面停留在断弦之上。

光线缓缓变暗。

可以听见极轻的风声，或留出短暂的寂静。

**镜头五：转入回忆（5—7秒）**

断弦的画面缓缓叠化为与它对应的真实剧情记忆。

可保留古琴作为视觉连接，使物件与人物命运发生关联。

这里必须调用已经存在的顺王、和妃及旧琴曲等相关剧情，核对断弦意象真正对应的章节。

不能因为画面好看就擅自改变故事事实。

### 3. 动画制作质量要求

断弦应体现物理上的连续运动，而非瞬时替换素材。

优先采用可调节的动画参数：

- 弦振幅
- 振动频率
- 断裂时刻
- 断点位置
- 弦段回弹幅度
- 回弹阻尼
- 镜头推近速度
- 失焦程度
- 灯火亮度
- 音效触发时刻

在技术上，可采用 SVG 路径动画、Canvas 绘制或现有可用的动画框架。

**技术方案必须以最终画面质量、动作连贯性和浏览器性能为依据，而不是选择最容易写的方案。**

如果纯 CSS 难以达到理想质感，就不要继续坚持纯 CSS。

## 四、其他重要镜头的重设计方向

以下是建议的视觉演出方案，必须先核实正式剧情后再采用。

### 1. 宫灯熄灭

不要只是把灯笼 opacity 从1改为0。

应当能够看到：

- 宫灯的灯罩、纹样与流苏
- 灯芯微微摇曳
- 灯光在附近帘幕上的变化
- 火光逐渐缩小
- 最后一瞬暖光消失
- 灯罩仍在黑暗中保留隐约轮廓

熄灭的是火，不是整个物体凭空消失。

### 2. 花落与花谢

不要用几个圆形粒子代表花瓣。

花瓣应有自然的形状、深浅和前后景关系。

可以让一枝真实的花出现在画面一侧。

一片花瓣离枝，随风缓缓落下。

镜头不必追逐花瓣，让它自然落在桌面或水中。

若需要表现多年流逝，可以通过同一枝花在不同季节的镜头衔接，而不是几秒内夸张地枯萎。

### 3. 诏书展开

不要只用黄色长方形向下拉伸。

应具有：

- 绢帛或纸张纹理
- 卷轴或文书的真实结构
- 自然的展开过程
- 案面上的投影
- 与剧情相符的文字或印记

文字出现必须有阅读节奏。

如果当前没有可靠的文书原文和美术素材，不得生成虚假的诏书内容。

### 4. 宫门闭合

不要使用两块矩形横向移动。

应体现真实宫门的体量：

- 朱漆门扇
- 门钉
- 门轴与门环
- 厚重的阴影
- 门扇移动时逐渐缩小的光缝

关门过程需要有重量感。

最后只留下一道窄光，随后彻底合拢。

### 5. 旧物与书信

如果走马灯中有信笺、旧琴、玉佩、旧簪、花瓶等物件，应采用明确的物件特写。

通过灯光、镜头和场景交叠呈现回忆。

不要让物件悬浮旋转，像商品展示动画。

### 6. 人物离别

不要把人物立绘机械地从左向右移出屏幕。

应该根据真实剧情选择：

- 人物转身
- 远景中的身影逐渐走远
- 镜头停留在留下的人身上
- 人物离开画面后，环境仍保留片刻
- 由旧日相逢场景叠化到多年后的同一地点

优先使用现有高质量人物素材和场景。

## 五、全面升级走马灯的镜头语言

当前走马灯不能只是一个个动画组件依次出现。

它需要形成连续的视觉叙事。

### 镜头变化

合理使用：

- 缓慢推近
- 局部特写
- 前景遮挡
- 焦点转移
- 景深变化
- 轻微横移
- 画面叠化
- 匹配剪辑
- 延迟消散

但不能每一幕都使用相同效果。

### 场景衔接

尽量让相邻镜头存在视觉联系。

例如：

琴弦断裂后，细长的断弦轮廓与下一幕的旧日书信发生自然叠化。

一盏宫灯熄灭，下一幕远处宫城中的灯火重新亮起。

曾经明亮的宫道，与多年后同一地点的寂静画面呼应。

这些衔接必须服务于真实情节。

不要为了炫技而制造与故事无关的转场。

### 情绪节奏

避免：

每一幕都是淡入 → 放大 → 淡出。

每一幕都出现大量金色粒子。

所有悲伤场景都配一个黑屏。

所有剧情高潮都使用白色闪光。

应该让不同记忆有不同的节奏。

有些瞬间可以很短。

有些镜头应该停留更久。

真正重要的不是每秒都有东西运动，而是观众愿意停在画面里。

- 每句诗都出现俗气的金色发光。

诗句应该像回忆中最后留下的一句话。
