# 《宫灯未眠》全篇语言终审与文学性精修 Prompt

## 一、任务目标

请完整读取当前《宫灯未眠／承熙纪事》项目的所有正式剧情文本，包括：

- 序章与故事背景
- 全部正式章节及章节内部的不同阶段
- 所有选项及其后续分支
- 人物对话、内心活动与叙事旁白
- 诏书、奏折、书信、宫廷记录
- 皇子女及后宫人物相关事件
- 插花、点茶、宫宴、请安等生活情节
- 终章、不同结局及结尾走马灯
- 与叙事有关的地图说明、人物介绍和大事录

**本次任务是对整部作品进行完整的文学编辑，不是简单校对，也不是推翻现有故事重写。**

请基于当前最新代码和真实剧情逐章修改。

最终目标：让全文达到成熟中文宫廷互动小说的语言水准——文笔优美而不做作，对话自然且有人物辨识度，情绪细腻，叙事流畅，既有宫廷气韵，也有真实生活的温度。

## 二、第一重点：清除刻意古风、拗口及不自然的表达

逐句检查全文是否存在以下情况：

1. 为了显得古雅而使用生僻、不合语境的词语。
2. 句式刻意倒装，正常读者需要反复读才能理解。
3. 本来一句自然的话，被写成复杂且不符合口语习惯的表达。
4. 叙述含混，读者无法明确谁在说话、谁在行动。
5. 人物对话过分书面化，像在背诵文章。
6. 表面上古雅，实际并不符合人物身份或语境的措辞。
7. 出现明显现代化、网络化、职场化的词汇。

特别检查以下曾经出现过的问题：

- “繁琐处理公务”
- “规则原则”
- 生硬的宫廷套话
- 含义不清的抽象判断
- 为古风而古风的复杂修饰

修改原则：

**古风不是让每一句话都变难懂，而是让人物的身份、礼节、生活方式和说话习惯自然体现时代氛围。**

例如：

原句：\
“此事牵涉诸多繁琐公务，朕尚需审慎权衡。”

可依据语境修改为：\
“这事还牵着前朝，朕得再想想。”

以上仅为示例。实际修改必须结合说话者的性格、身份、情绪与具体情境。

不要把所有人物都改成现代口语，也不要把所有对话都改成半文半白。

## 三、第二重点：全面消除明显的 AI 写作痕迹

请重点搜索全文中反复出现的语言模式。

### 1. 抽象词过度重复

例如：

- 分寸
- 规矩
- 体面
- 筹码
- 棋局
- 退路
- 轻重
- 代价
- 选择
- 心思
- 局势

这些词并非不能使用，而是要检查：

是否很多不同人物都在说同样的话？

是否每段重要对话都绕回“规矩、分寸、代价”？

是否人物明明有具体处境，却只用抽象概念讨论问题？

如果是，请根据事件本身改为更具体的表达。

### 2. 套路化句式

重点检查：

- “不是……而是……”
- “她知道……”
- “他终于明白……”
- “仿佛……”
- “似乎……”
- “这一刻……”
- “从这一日起……”
- “谁也没有想到……”
- “话音落下……”
- “殿内一时无声……”
- “她没有回答，只是……”

这些结构并非禁止使用，但如果频繁出现，会让整部作品产生明显的模板感。

不要通过机械替换同义词来掩盖重复。

必须重新判断每一段是否需要这样的句子。

### 3. 过度解释情绪

例如：

“她知道，此刻的沉默意味着两人之间的信任已经出现裂痕。”

如果人物的动作、前后对话已经能够体现裂痕，就不必再向读者解释。

可以让人物继续谈话、转移话题，或在某个具体动作上表现迟疑。

**相信读者能够理解人物，不要替读者把每一种情绪都总结出来。**

### 4. 过度使用文学性金句

不要让每个人在普通谈话中都说出人生哲理。

尤其避免：

- 每个场景最后都有一句意味深长的总结
- 每一次告别都像最终诀别
- 每一次争执都被上升到权力与命运
- 每一次吃茶、赏花都被解释成人生隐喻

真正的文学性来自具体的人和事，而不是不断制造金句。

## 四、第三重点：逐个人物检查语言辨识度

请先从完整剧情中归纳每个重要人物的性格、身份、成长经历、说话方式和前后期变化。

然后逐章检查人物台词。

重点人物包括：

### 杨叙（皇帝）

他的语言需要随年龄、经历与帝王责任变化。

早期可以保留年轻人的情绪和不成熟。

中期逐渐形成帝王习惯。

后期更沉稳，也可能更疲惫。

但不能让他始终像一个冷静的政治评论者。

他有私心、有不耐烦、有温柔，也会说不合时宜的话。

要保留他的复杂性。

### 顾明宜

注意她作为旧日嫡福晋、皇后，以及重大事件中的不同状态。

不能始终写成一个端庄、正确、全知的符号。

她可以有自己的喜好、烦恼、犹豫和不愿说出口的事情。

要让读者感受到她首先是一个具体的人，其次才是皇后。

### 张元照

她的人物成长应当通过语言变化自然体现。

不要让早期的她拥有后期才形成的政治判断和处事方式。

也不要让后期的她突然变成只会说权谋术语的人。

她的坚韧应体现在处理具体事情的能力上，而不是反复宣称自己懂得取舍。

### 闻人含章

保留她既定的性格张力和人物成长。

不要将她简单写成神秘、冷艳、聪慧的固定形象。

让她有真实的喜怒、习惯与情绪失控的时刻。

### 周清漪

保留她在重大事件中的鲜明判断和行动力。

但是不能让每一句话都像带着锋芒的质问。

在不同的人面前，她应当有不同的态度与说话方式。

### 太后邵令仪

她的威严应来自身份、经历与说话方式，不需要不断用严厉台词强调。

她同样可以有日常习惯、私人情绪与不愿表露的关切。

### 其他人物

卢云岫、邵明贞、霍素英、崔静仪、王静娴、张元照之外的妃嫔、顺王、皇子女以及宫人，都要具有符合其身份的语言特点。

尤其注意：

**孩子说话必须符合年龄。**

不得把皇子女写成缩小版的成年政治人物。

宫女与内侍也不能全部使用相同的机械套话。

最终目标是：隐去说话者姓名后，熟悉故事的读者仍然能够在不少重要对话中辨认人物。

## 五、第四重点：加强对话的真实感和情绪层次

逐场检查所有重要对话。

重点判断：

1. 人物为什么要说这句话？
2. 她是否真的会对眼前这个人这样说？
3. 这句话是表达真实想法、掩饰情绪，还是争取某种结果？
4. 对方的回答是否真正回应了上一句话？
5. 对话是否推进了事件或人物关系？
6. 是否存在为了向读者解释剧情而强行加入的台词？
7. 是否反复让人物直接说出自己的真实动机？

不要把对话写成一问一答的剧情说明书。

允许出现：

- 答非所问
- 说到一半停住
- 有意转移话题
- 因为误会而产生不愉快
- 明明关心却说得不够好听
- 平凡的玩笑
- 不必要的小争执
- 一个人说完之后，另一个人没有立刻理解

但这些细节必须符合具体人物，不能为了制造生活感而随意添加。

人物关系的变化应该通过前后对话逐渐形成，而不是依赖旁白宣布关系改变。

## 六、第五重点：重做不自然的场景转场

请检查每一章内部以及相邻章节之间的衔接。

重点寻找：

- 对话结束后突然切换地点
- 上一个情绪尚未结束，下一个事件已经开始
- 时间跳跃没有交代
- 某位人物无缘无故出现在另一座宫殿
- 重要事件结束后缺少必要余波
- 大量使用“数日后”“与此同时”“转眼间”机械连接
- 人物刚刚经历重大变故，下一场却毫无影响

转场不应全部依靠旁白介绍。

可以通过自然细节体现：

- 宫门开启或关闭
- 更鼓、天色、天气变化
- 宫人收拾茶盏
- 次日请安
- 送来的书信
- 更换的衣物与陈设
- 某位人物的再次出现

尤其需要检查重大情节之后的情绪连续性。

**事件结束了，不代表人物的情绪也立即结束。**

不要让人物在一场悲剧之后，下一段就恢复成完全没有受影响的日常状态。

## 七、第六重点：加强生活感，但避免流水账

检查最近新增的茶食、插花、点茶、宫宴、赏花和宫中起居片段。

必须同时满足：

1. 文化细节准确。
2. 人物行为自然。
3. 描写具有视觉与感官体验。
4. 不像历史知识介绍。
5. 不为展示物品而罗列名词。
6. 能够体现当下人物关系。
7. 不抢夺章节真正的叙事重点。

例如，不需要每次饮茶都写明茶叶品种、产地、水温、器具与点心名称。

可以重点写人物的一个小习惯：

有人不喜甜食，却仍接过对方递来的糕点。

有人习惯等茶凉一些再喝。

有人在别人讲话时，慢慢剥开松子的外壳。

这些细节应当偶尔出现，保持自然。

不要使全篇充满人为安排的象征与伏笔。

## 八、第七重点：增强重要章节的文学感染力

请找出全篇真正重要的情节，包括但不限于：

- 顾明宜相关重大事件与最终离世
- 皇嗣相关的重要抉择
- 疫病之后宫廷重新恢复秩序
- 后位空悬与继后之争
- 重要人物之间的关系决裂
- 抱朴刺杀事件
- 张元照的关键成长阶段
- 杨叙生命晚期及其驾崩
- 新朝开启
- 终章与走马灯

这些章节的语言应当更加细腻、有力度，但不是简单增加形容词或篇幅。

重点检查：

**重大事件发生之前**

是否有足够自然的铺垫？

**事件发生之时**

是否有具体人物反应，而不是只有概括叙述？

**事件结束之后**

是否留下恰当的情绪余波？

尤其避免：

“从此，一切都改变了。”

“这一夜，所有人的命运都走向不同的方向。”

类似句子如果没有具体内容支撑，应该删除或重写。

### 关于死亡与离别

不必每次都写得声嘶力竭。

有时更加令人难过的，是人物离去之后，原本平凡的生活细节突然变得不同。

可以通过旧物、习惯、熟悉的地点与真实人物反应营造情绪。

但不能将所有悲剧都处理成同一种空殿、残灯、旧物的固定模板。

## 九、第八重点：严格统一不同文本体裁

《宫灯未眠》不只有一种叙述语言。

请分别检查：

### 正文叙事

自然、流畅、细腻，具有真实场景与人物动作。

### 人物对话

与身份、关系和情绪匹配，语言有生活感。

### 诏书与正式文书

庄重、简洁，符合架空王朝所采用的宫廷文书风格。

避免现代行政语言，也不要堆砌无意义的文言。

### 大事录

保持史书纪事体的简洁与客观，不要写成抒情散文。

### 人物介绍

以人物实际经历和当前状态为准，不提前剧透尚未发生的情节。

### 序章

严格遵守主控视角与时间顺序，只呈现开篇时合理可知的世界背景。

**禁止为了增加悬念而提前透露后续死亡、继后结果或关键反转。**

### 结局走马灯

保持克制。

诗句、旧日回忆与结局画面已经承担情感作用，不需要在每段回忆后继续解释人物命运。

保留现有正式题辞、诗句和结局核心表达，不得擅自更改。

## 十、第九重点：检查叙事视角和时间逻辑

本作以皇帝作为主要玩家视角，同时存在必要的多视角叙述。

请检查：

- 主控是否突然知道不可能知道的秘密？
- 是否未经转场就进入另一人物的内心？
- 是否在正常剧情中提前揭示隐藏动机？
- 不同视角切换是否明确？
- 人物年龄、时间和身份是否与章节一致？
- 前期人物是否说出了只有后期才会懂得的话？
- 是否存在人物已去世却仍参与普通剧情的问题？
- 事件的先后顺序是否被文学性改写破坏？

允许合理的叙事留白，但不得制造信息错误。

**文学润色不能牺牲剧情逻辑。**

## 十一、逐句语言质量检查标准

每段文字请按照以下标准自查：

| 检查维度 | 具体要求           |
| ---- | -------------- |
| 准确性  | 语法、搭配、指代正确     |
| 自然度  | 符合中文阅读习惯       |
| 古风感  | 有时代气质但不过分文言    |
| 人物性  | 台词符合说话者        |
| 画面感  | 抽象叙述有必要的具体支撑   |
| 情绪   | 尽量通过场景、动作、对话体现 |
| 简洁度  | 删除重复解释和无效修饰    |
| 节奏   | 长短句与场景情绪匹配     |
| 连贯性  | 前后事件、对话自然衔接    |
| 文学性  | 有美感，但不刻意炫技     |

不要把精修误解成全部变短。

该简洁的地方简洁。

该舒展的地方舒展。

高潮可以有适当的描写密度，平凡日常也允许留白。

必须保留不同章节应有的快慢节奏。

## 十二、执行方式：三轮完整检查

### 第一轮：全篇定位

完整遍历所有正式剧情文本，包括分支和隐藏内容。

找出：

- 不自然的台词
- 重复用词与句式
- AI 感明显的旁白
- 过度抒情
- 生硬转场
- 逻辑不通的表达
- 人物语言同质化
- 称谓与时间线错误

建立内部问题清单。

不要只检查前几章或首页可见内容。

### 第二轮：逐章实际修改

按故事时间顺序精修每一章。

要求：

- 对存在问题的句段进行实际修改。
- 已经自然、准确、有表现力的句子尽量保留。
- 不得为了体现工作量而改写全部句子。
- 不得改变原有剧情事实、角色命运及选项因果。
- 不得随意增删关键台词。
- 不得将多个角色的语言统一成一种文学腔。
- 不得把原本有力度的短句扩展成冗长抒情。
- 不得改动剧情节点的 ID、存档键值或程序依赖的数据结构。

本次工作是**精修原著，不是生成另一版故事。**

### 第三轮：真实读者通读

完成全部修改后，再从序章一直通读到终章。

不要只依靠单句校对结果判断质量。

重点检查：

1. 读起来是否自然顺畅？
2. 是否还有大量同样的表达反复出现？
3. 重要人物是否有自己的声音？
4. 对话是否有真实交流的感觉？
5. 不同章节之间是否有情绪断裂？
6. 哪些地方还显得太像 AI 生成？
7. 哪些场景只是漂亮，却没有实际内容？
8. 哪些地方过度解释，剥夺了玩家自行理解的空间？
9. 有没有文学性很强却不符合人物性格的句子？
10. 读完整个故事后，人物是否真正令人记得住？

重点关注：读者是否会因为人物的经历而产生情绪，而不是因为旁白要求读者感动。

## 十四、交付结果

请直接完成项目中的实际润色修改，最终给我一份精简但具体的报告。

报告包含：

**1. 全文语言问题概览**

指出全篇最严重的3—5类写作问题。

**2. 逐章修改摘要**

注明每章主要解决了什么问题，不用逐条罗列所有文字修改。

**3. 典型修改对比**

选取至少10处最有代表性的修改，展示：

原句 → 修改后 → 修改原因。

优先选择人物台词、旁白、转场和情绪表达的不同类型。

**4. 人物语言一致性**

指出有哪些人物曾经存在明显的语言同质化，以及如何修复。

**5. 未解决问题**

如发现需要调整剧情结构才能彻底修复的问题，不得擅自大幅重写，应单独列出。

**6. 功能验证**

说明检查的文件、测试方法和实际结果。

## 十五、最高优先级原则

请牢记：

**《宫灯未眠》不是一篇不断讨论权力、规矩和命运的议论文，而是一群真实人物共同经历的漫长岁月。**

他们有各自的欲望、局限、习惯和感情。

他们会算计，也会犯错。

会因为大事争执，也会因为小事不快。

会在宫宴上微笑，在无人处疲惫。

也会有一些日子，什么惊天动地的事都没有发生。

不要让每个角色都成为作者表达主题的工具。

不要让每段对话都承担政治寓意。

不要让每个章节都以一句人生感悟收束。

不要让每场悲剧都用相同的意象渲染。

允许故事有安静的地方、笨拙的地方、温暖的地方和不完美的地方。

**最终要求：文字应当让玩家忘记自己正在阅读一段经过设计的剧情，而是真正相信，承熙朝的这些人曾经这样生活过。**

请开始完整审查并实际修改，不要仅输出计划或建议。

这次我特别建议要求 Codex 先识别每个人物的语言特点，再逐章润色。否则它很容易把所有人的台词统一改成同一种“精致古风文笔”，虽然单句看起来漂亮，但整部作品的人物反而变得更加相似。

另外，之前确定的结局文字和诗句尽量保持不动，把精修重点放在人物如何一步步走到那个结局。
