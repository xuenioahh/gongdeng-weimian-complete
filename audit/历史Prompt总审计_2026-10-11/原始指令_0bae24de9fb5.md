# 《宫灯未眠》宫廷地图重设计 Prompt（沉浸美术 / UI 优化版）

请重新设计《宫灯未眠》中“宫廷地图 / 宫廷舆图”页面。  
当前版本的**地理位置基本正确，不需要推翻重做布局逻辑**，但整体视觉效果过于简陋，像功能示意图或低保真草图，**缺少古风宫廷游戏应有的美感、氛围和沉浸感**。

本次目标不是改地图逻辑，而是：

> **在保留现有宫城空间关系、方位信息、宫殿名录和角色居所设定的前提下，把这张地图提升成《宫灯未眠》世界观中的正式页面，让玩家一打开就感觉自己正在翻阅一张承熙朝宫禁舆图。**

## 一、核心目标

这张地图必须同时做到四件事：

1. **位置清楚**
   - 玩家能迅速看懂内廷、外朝、东西翼、御花园、太液池、前朝、太医院、顺王府等位置关系。
   - 南北中轴、城门、宫城边界必须明确。

2. **视觉好看**
   - 地图要有古风质感，不能只是浅色背景上摆一堆矩形框。
   - 整体要精致、统一、耐看，适合长期放在游戏系统页中。

3. **有沉浸感**
   - 这不是现代网页流程图，而是玩家在《宫灯未眠》中看到的一张“宫中地图”。
   - 要有“深宫规制、内外有别、步步成局”的感觉。

4. **有故事气质**
   - 地图不仅告诉玩家哪里在哪里，还应该让玩家感受到：
     - 凤仪宫为何重要
     - 御花园与太液池为何适合发生故事
     - 顺王府为何在城外
     - 宫中人物的距离，也隐含着权力与关系的距离

---

## 二、整体设计方向

请把这一页从“功能框图”升级成：

> **古代宫廷舆图 + 游戏内系统地图 + 剧情辅助页面**

整体视觉参考方向：

- **宫廷档册中的舆图**
- **古风游戏内置地图页面**
- **带轻微手绘感的宫城平面图**
- **有纸张、印记、宫墙、朱印、题签质感**
- **克制、雅致、规整、可读**

不是做成写实鸟瞰大场景图，也不是做成复杂 3D 地图。

最适合的是：

> **“二维平面布局 + 古风精修材质 + 叙事感细节 + 轻互动高亮”**

## 三、必须保留的内容

以下内容是本次优化中**必须保留**的，不要随意推翻：

1. **整体方位逻辑**
   - 北在上，南在下
   - 内廷 / 外朝 / 东西翼 / 城外关系
   - 城门与出入口方向

2. **主要建筑位置关系**
   - 御花园、太液池、凤仪宫、景仁宫、景阳宫、永和宫、慈宁宫、养心殿、太医院、尚膳局、前朝、待卫值房、西华门、顺王府等

3. **现有地图的“结构准确性”**
   - 现有位置若已经符合你设定，不要为了美观胡乱搬宫殿

4. **地图的功能性**
   - 玩家仍然需要快速辨认宫殿和区域，而不是只看氛围

本次工作重点是**美术表达、信息层级、页面体验和沉浸感**，不是重新发明地图结构。

## 四、视觉风格要求

### 1. 地图底图材质

当前底色太像普通网页底。

请改为更有质感的底图风格，例如：

- 仿古纸张
- 淡米色、暖灰米、旧绢色底
- 带轻微纸纹、纤维感、墨痕、旧卷边缘阴影
- 可有很浅的宫廷纹样暗纹（回纹、云纹、团花纹等），但不能抢文字

要让地图像：

> **一页从宫中档册、内务图册或掌故簿中展开的宫禁地图。**

---

### 2. 宫城边界与建筑表达

当前所有建筑都像统一浅棕方块，缺少层级。

请优化为：

#### 宫城外围
- 用更明确、更有质感的宫墙边框
- 体现“宫城轮廓”
- 可略带朱砂色 / 深褐红边线，表现宫墙

#### 主体建筑
- 不要全部用一模一样的扁平矩形
- 可以保留平面几何形，但需加入：
  - 屋宇感
  - 殿宇层级
  - 不同功能建筑的区分
- 比如主宫殿稍厚重，配殿略小，园林/池水更柔和

#### 重要宫殿重点突出
例如：
- 凤仪宫
- 慈宁宫
- 养心殿
- 前朝
- 御花园
- 太液池

这些地方在视觉上必须更醒目，不能与普通建筑完全一个级别。

可以通过以下方式体现：
- 色块深浅变化
- 细描边
- 屋顶样式小图标
- 边框装饰
- 题签底色不同

目标是让玩家一眼知道：  
**这里是故事的核心舞台，不只是另一个方块。**

---

### 3. 园林与水体

目前太液池和御花园仍然偏功能框。

请把它们做得更有氛围：

#### 御花园
- 使用更柔和的绿色 / 青绿色区域
- 可加入浅浅树影、园林纹理、花木点缀感
- 不要做成儿童地图式草地块
- 要像“宫中一片可供赏花游园的真实空间”

#### 太液池
- 水面应比普通建筑更轻、更灵动
- 可以带一点水纹、池岸曲线、浅淡反光感
- 和硬朗宫殿形成质感对比

这两处是最容易制造沉浸感的区域，必须比现在更“可进入”。

## 五、信息层级优化

### 1. 区域层级

请明确区分：

- 宫城范围
- 内廷
- 外朝
- 东翼 / 西翼
- 城外

不要所有文字都在同一个视觉层。

建议做法：

- **一级信息**：宫城大区域（内廷、外朝、城外）
- **二级信息**：重要宫殿与关键地点
- **三级信息**：说明文字、示意注、辅助标识

一级应最稳重，二级最实用，三级最克制。

---

### 2. 标签样式

当前标签太像网页白色小框贴纸。

建议改成更统一的古风标注形式，例如：

- 小型题签
- 米色笺片样标签
- 淡金边 / 褐边
- 小圆点指引 + 简洁引线
- 更像“图上题注”，不是网页按钮

标签要求：

- 清晰易读
- 不压住主体建筑
- 不凌乱
- 不要现代感太强的圆角浮层风格

---

### 3. 字体与文字风格

请统一文字气质：

- 标题“宫廷地图”可以更像“宫禁舆图”或“宫城图”
- 页面小标题、图注、方向文字都要更古雅
- 可考虑：
  - 页面主标题偏题签感
  - 地图内部标识简洁、清晰、不花哨
  - “北 / 南 / 内廷 / 外朝”等尽量更稳重

不要使用过于现代的 UI 字体风格去破坏氛围。

---

## 六、沉浸感增强方式

### 1. 地图外框与装饰

可以加入轻微的地图装帧感：

- 卷轴边框感
- 四角轻装饰
- 页面题签
- 淡淡印章 / 宫印 / 内府图记感
- 页边留白像图册

注意必须克制。  
不是做成古风模板网站，也不是大量花边堆砌。

目标是：

> **像游戏里的“系统地图页”，而不是淘宝古风背景图。**

---

### 2. 轻微动态效果

这张地图可以适当“活一点”，但一定要克制。

可考虑：

- 当前 hover 到宫殿名时，对应区域轻微高亮
- 重要宫殿有轻微呼吸光或微亮边缘
- 太液池可有极轻微波纹动效
- 御花园可有极淡花影 / 光影浮动
- 标签弹出时平滑、安静，不要夸张飞入

千万不要：

- 做成满屏闪光
- 大量漂浮花瓣
- 炫目粒子
- 明显游戏地图光污染

---

### 3. 剧情辅助交互

若当前系统结构允许，请增强“地图与故事的关系”：

#### hover / 点击宫殿名时
可以显示简短信息卡，内容如：

- 宫殿名
- 当前或曾经居住的人物
- 简短一句剧情感描述
- 不剧透的功能说明

例如：

**凤仪宫**  
中宫所在。顾皇后曾居于此，后位空悬之后，宫门虽开，灯火却不复如昔。

**景仁宫**  
徽妃邵明贞所居，殿宇稳重，行事亦如其人。

**御花园**  
宫中四时景色最盛之处，亦是许多相逢与试探发生的地方。

注意：  
不是做百科全书，不要一次弹太多字。  
而是让地图“带一点剧情余味”。
